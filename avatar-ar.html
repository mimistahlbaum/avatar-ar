Avatar AR · research prototype v0.2

This tool uses your device camera to track body movement and draw an avatar over it, entirely in your browser.

  • What is captured: the camera image is used locally for pose tracking. If you press rec, the recording contains the avatar rendering only, never the camera image. Optional landmark logging saves body joint coordinates as numbers, not images.
  • Nothing is uploaded: there is no server. Camera footage, landmark data and metadata never leave this device through this tool.
  • Local downloads: when a recording stops, the video file, a metadata JSON file and, if enabled, a landmark JSON file are downloaded to this device.
  • Session fields: participant ID, condition label and session notes are saved only into the downloaded metadata files. Leave them blank if you prefer.
  • You can stop at any time by closing this page. Downloaded files stay on your device and can be deleted by you.
